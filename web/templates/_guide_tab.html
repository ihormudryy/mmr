Dashboard user guide

Control room for your paper or live IB account at /cc. Hover the iSame info bubbles as on the Deploy and Watchlists tabs — hover or focus to read. bubbles for extra help.

If commands are disabled you can watch everything but cannot place, approve, or cancel trades.

If you are new to trading {{ info('Read this section once before approving anything on LIVE. Paper mode is the safe practice sandbox.') }}

What this dashboard is {{ info('Nothing spends real money until you are on LIVE and you Approve (and confirm) a trade.') }}

  1. Strategies (or you) suggest trades.
  2. Suggestions become proposals — not trades yet.
  3. You Approve → an order goes to the broker.
  4. When filled, you hold a position (shares long or short).

Why “propose” instead of “buy now”? {{ info('Strategies with auto_execute: propose also create proposals — you still Approve or Reject each one.') }}

So you can check size and thesis before anything hits the market.

Safety habits

  1. Prefer paper until comfortable.
  2. Prefer auto-sizing (leave quantity and amount empty).
  3. Read the Action queue card before Approve.
  4. On LIVE, read the confirm drawer (side, quantity, notional).
  5. Use Pause new trading if something looks wrong.
  6. Yellow/red chips or “Risk unavailable” → do not assume the book is fine.

Example A — Manual buy on paper {{ info('Best first exercise. Leave quantity and amount empty for automatic position sizing.') }}

  1. Terminal: mmr resolve AAPL → note the conId.
  2. Trading → Action queue → New proposal → Resolve a symbol (or paste conId).
  3. conId + Side BUY; leave size empty; confidence e.g. 0.6; short reasoning.
  4. Create proposal → review card → Approve.
  5. Watch Working orders → Executions → Positions.

Reject instead of Approve anytime — nothing was sent yet.

Example B — Close part of a position

  1. Positions → Close.
  2. Lower quantity to close only part → Create → Approve.

Example C — Pause when unsure

  1. Strategies header → Pause new trading (immediate).
  2. Resume when ready (live may ask to confirm).

Example D — Cancel a stuck order {{ info('Cancelling a protective stop on LIVE is risk-increasing — it can leave a position unprotected and needs confirm.') }}

  1. Working orders → Cancel on the leg, or Cancel all.

Deploy tab {{ info('Turns a strategy file into a running algo. Needs symbols OR a watchlist — exactly one.') }}

Example E — Deploy on a small US list

  1. Watchlists: create tech_demo, add AAPL, MSFT.
  2. Deploy → unfold a strategy → name e.g. orb_demo.
  3. Pick watchlist tech_demo (or type symbols — not both empty).
  4. Optional: check propose so signals become proposals.
  5. Deploy → Enable on Trading when needed.

Undeploy is on the Deploy tab (confirm), or: mmr strategies undeploy orb_demo

Watchlists tab {{ info('Reusable symbol groups resolved to exact IB contracts — never guessed.') }}

Example F — ASX names

  1. Create asx_miners.
  2. manage → symbols BHP, RIO → exchange ASX → currency AUD → Add.
  3. Use that watchlist on Deploy so you get Australian listings, not a US ticker with the same letters.

Suggested learning path

  1. Confirm badge says PAPER.
  2. Do Example A (manual propose → approve → position).
  3. Do Example B (close it).
  4. Build a tiny watchlist and deploy one strategy with propose.
  5. Approve or reject one strategy-made proposal.
  6. Only then consider LIVE — treat every confirm as real money.

Tips

  • Use conIds in New proposal (exact contract).
  • Drawers: Cancel, ×, or Escape closes without sending.
  • Deploy needs symbols or watchlist — empty submit shows an error flash.
  • Missing risk data ≠ “all clear.”
  • When confused: Pause → reject pending proposals → investigate → Resume.
